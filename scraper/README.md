# Books to Scrape — Web Scraper

A robust, polite, and fault-tolerant web scraper built to extract book catalogue details from [Books to Scrape](https://books.toscrape.com/).

---

## Target Classification
* **Target Site**: `https://books.toscrape.com/`[cite: 1]
* **Purpose**: Sandbox environment explicitly built for practicing web scraping.[cite: 1]
* **Scope**: First 3 catalogue pages only (60 books total).[cite: 1]
* **Data Collected**: Title, product URL, price text, numeric price (GBP), availability text, rating, description, source page URL, and fetch timestamp.[cite: 4, 5]
* **Robots.txt Result**: `no robots file found`[cite: 1]
* **Declaration**: I will not reuse this code on another site without checking its rules and terms first.[cite: 1]
